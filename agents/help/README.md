# help — 能力说明（不检索）

回答"你能做什么"。这类问题问的是本系统，交给联网检索会跑偏。

## 流程

```mermaid
flowchart TD
    A[能力类问题] --> B[查当前租户数据<br/>任务数/记录数/会话数]
    B --> C[拼系统提示词<br/>真实能力清单 + 数据现状]
    C --> D[模型组织回答]
    D --> E{模型可用?}
    E -->|否| F[退回固定清单]
    E -->|是| G[分点 + 举例]
    G --> H[返回]
    F --> H
```

## 为什么答案是模型生成的

写死文案会过期（"现在有 4 个 Agent"），也答不了"你能分析股票吗"这类追问。
模型拿到的是**真实能力清单 + 当前租户数据**，所以它说的是"现在真有的"。
