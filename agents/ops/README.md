# ops — 运维操作

管理采集任务、清理导出目录与缓存、回收站、审批与审计。
**所有破坏性操作都过网关**，不是直接调函数。

## 破坏性操作流程（网关）

```mermaid
flowchart TD
    A[模型/面板发起] --> B[策略判定<br/>LOW/MEDIUM/HIGH]
    B -->|BLOCK| X[拒绝并审计]
    B -->|SOFTEN| C
    B -->|需审批| P[生成审批票据<br/>绑定参数指纹]
    P --> Q{管理员批准?}
    Q -->|否| Y[拒绝并留痕]
    Q -->|是| C
    C{幂等键已用?}
    C -->|是| R[返回上次结果]
    C -->|否| S[预算检查]
    S --> T[快照]
    T --> U[意图审计]
    U --> V[执行]
    V --> W{校验通过?}
    W -->|是| Z[结果审计]
    W -->|否| Y2[回滚 + 异常审计]
```

## 关键文件

| 文件 | 作用 |
|---|---|
| `gateway.py` | 执行网关（幂等→审批→预算→快照→审计） |
| `policy.py` | 声明式策略：风险等级与决策 |
| `approval.py` | 审批票据（Redis，绑定指纹，15 分钟过期） |
| `audit.py` | `ops_audit` 两阶段审计（意图 → 结果） |
| `trash.py` | 软删除：移入回收站、恢复、永久清除 |
| `cleaner.py` | 导出目录清理计划 |
| `cache_maintenance.py` | 缓存巡检（问答缓存 + 分析缓存） |
| `graph.py` | 运维 Agent 的工具调用循环 |
