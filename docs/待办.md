# 待办与已知问题

## 已知问题

### 1. `web_enhanced` 路径不是流式输出

**现象**：走「知识库无结果 → 补公网证据」这条升级链路时，前端会等全部生成完再一次性显示整段答案，而不是逐字出现。

**原因**：`agents/qa/compose.py::compose_answer` 用的是 `llm.ainvoke`，不是 `astream`。qa 和 research 的常规路径都走 `_stream_or_invoke`（有 `get_stream_writer` 时边生成边推），但 compose 是在**图外面**被编排器调用的，拿不到 stream writer。

**修法（未做）**：给 compose 加一个可选参数，把 token 通过回调推给调用方；`orchestrator.stream_auto` 把它转成 `{"type":"token"}` 事件。或者把 compose 包成一个只有单个节点的临时图，借 LangGraph 的 custom stream。

**影响**：仅体验问题，答案内容与正确性不受影响。
